# Goal Challenge 3D

Kleines 3D-Fußballspiel für Android, gebaut mit Godot 4.4.1.
Ball durch Ziehen und Loslassen schießen, 300 Level mit steigender Schwierigkeit.

## APK herunterladen

- **Neueste Testversion:** Reiter *Actions* → letzter grüner Lauf → unten bei *Artifacts* „Goal-Challenge-Android“ (ZIP mit der APK).
- **Veröffentlichte Versionen:** Bereich *Releases* rechts auf der Startseite.

Zum Installieren auf dem Handy muss „Apps aus unbekannten Quellen“ erlaubt sein.

## Bauen

Jeder Push auf `main` baut automatisch eine Debug-APK (siehe `.github/workflows/android.yml`).
